## 简介
本指南面向FH6汽车设置工具的开发者，提供从代码贡献到部署运维的全流程开发文档。项目采用现代化的Next.js 14全栈架构，结合TypeScript、Tailwind CSS和现代React生态系统，支持服务端渲染、静态生成和流式AI响应。项目采用Monorepo结构，包含客户端、服务端、共享类型与工作区脚本，提供完整的开发工具链支持。

## 项目结构
项目采用工作区（workspaces）组织，采用Next.js 14的应用程序目录结构，主要模块如下：
- 根工作区：统一脚本与依赖管理
- client：Next.js客户端应用，基于App Router架构
- server：后端服务，基于Express，提供健康检查与聊天接口
- shared：共享类型定义，供前后端复用
- .gitignore：版本控制忽略规则

### 聊天路由与AI集成
- 参数校验：确保消息数组非空且为数组
- 认证：检查AI API Key是否存在
- 流式响应：使用SSE向客户端推送增量内容
- 错误处理：根据响应头是否发送决定返回JSON或SSE错误事件

```mermaid
flowchart TD
Start(["请求进入 /api/chat"]) --> Validate["校验 messages 参数"]
Validate --> Valid{"参数有效？"}
Valid --> |否| Return400["返回 400 错误"]
Valid --> |是| CheckKey["检查 AI_API_KEY"]
CheckKey --> HasKey{"存在密钥？"}
HasKey --> |否| Return401["返回 401 错误"]
HasKey --> |是| CreateProvider["创建 AI Provider"]
CreateProvider --> Stream["streamText(...) 创建流"]
Stream --> SetHeaders["设置 SSE 头部"]
SetHeaders --> ReadLoop["循环读取流数据"]
ReadLoop --> Done{"读取完成？"}
Done --> |否| WriteChunk["写入数据块"]
WriteChunk --> ReadLoop
Done --> |是| EndStream["结束流"]
ReadLoop --> |异常| HandleError{"响应头已发送？"}
HandleError --> |否| Return500["返回 JSON 错误"]
HandleError --> |是| SendErrorEvent["发送 SSE 错误事件"]
SendErrorEvent --> EndStream
```

## 性能考虑
- 编译目标与模块：ES2022目标与CommonJS模块便于Node运行时兼容
- 严格模式与类型声明：开启严格模式与生成.d.ts与.d.ts.map提升类型安全性与IDE体验
- 源码映射：启用sourceMap便于生产调试
- 路径映射：@shared路径别名简化导入
- Next.js优化：自动代码分割、预取和静态生成优化
- Tailwind CSS：按需生成CSS，减少bundle大小
- SSE流式：聊天接口使用SSE减少一次性响应体积，提升交互体验
- 内存管理：流式读取避免大对象堆积；错误处理中释放reader锁并结束响应

## 故障排除指南
- 端口占用：确认端口配置与防火墙设置

- SSE连接中断：检查网络稳定性与代理设置
- 类型不匹配：使用共享类型保持前后端契约一致
