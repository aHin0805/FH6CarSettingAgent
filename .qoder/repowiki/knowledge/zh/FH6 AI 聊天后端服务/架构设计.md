- **入口与配置**：`src/index.ts` 加载 `dotenv` 并启动 Express 服务器，监听端口由环境变量 `PORT` 控制（默认 3001）。
- **应用核心**：`src/app.ts` 定义 Express 实例，配置 CORS（允许 localhost:3000）、JSON 解析中间件、全局错误处理以及 `/api/health` 健康检查接口。
- **业务路由**：`src/routes/chat.ts` 实现 `/api/chat` POST 接口，接收消息历史，通过 `ai` 库的 `streamText` 结合 DeepSeek 模型进行流式响应（SSE）。
- **AI 集成**：依赖 `@ai-sdk/openai` 和 `ai` 库，通过环境变量动态配置 API Key、Base URL 和模型名称，支持工具调用（`tuningTools`）。
- **工具模块**：`src/utils/id.ts` 提供基于 `crypto.randomUUID` 的 ID 生成能力。
